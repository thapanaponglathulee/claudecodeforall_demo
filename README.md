# ช้อนทอง — หน้าดูเมนูและคิดราคา

เว็บหน้าเดียวสำหรับดูเมนูร้าน **ช้อนทอง ข้าวแกงเมืองทองธานี** กดเลือกจานที่อยากกิน
แล้วเห็นยอดรวมทันทีก่อนจะไปสั่งจริง

> หน้านี้ทำขึ้นเพื่อฝึกเขียนโค้ด **ไม่ใช่หน้าสั่งอาหารของร้าน** กดปุ่มในหน้านี้ไม่ได้ส่งออเดอร์ไปที่ไหน
> ปุ่ม "ไปสั่งจริงที่ LINE MAN" แค่เปิดลิงก์หน้าร้านของจริงให้เท่านั้น

## วิธีเปิด

โปรเจกต์นี้ใช้ Redux Toolkit ซึ่งโหลดผ่าน `<script>` ตรง ๆ ไม่ได้ จึงต้องติดตั้งก่อนหนึ่งครั้ง

```bash
npm install
npm run dev        # เปิด dev server พร้อม hot reload
```

| คำสั่ง | ทำอะไร |
|---|---|
| `npm run dev` | dev server สำหรับทำงานและตรวจงาน |
| `npm run build` | สร้างไฟล์สำหรับ deploy ลง `dist/` |
| `npm run preview` | เปิดดูผลของ `build` ก่อนเอาขึ้นจริง |

double-click ที่ `index.html` **ใช้ไม่ได้แล้ว** ตั้งแต่ย้ายมาใช้ Redux Toolkit
(ดู [ADR-0003](./docs/adr/0003-redux-toolkit-with-vite.md))

## สิ่งที่ทำได้ในหน้านี้

- ดูเมนูทั้ง 48 รายการ แยกตามหมวด พร้อมรูปและราคา
- ค้นหาจากชื่อเมนูหรือคำอธิบาย
- กรองตามหมวด หรือดูเฉพาะ "เมนูแนะนำ" ที่ร้านคัดไว้
- กด `+` / `−` เลือกจำนวน แล้วดูยอดรวมที่แถบล่างจอ
- กดที่รูปเพื่อดูรูปใหญ่ พร้อมราคาและปุ่มเลือกจำนวนในกล่องเดียวกัน
- ปิดเว็บแล้วเปิดใหม่ รายการที่เลือกยังอยู่ (เก็บในเครื่องผู้ใช้)

## ข้อมูลเมนูมาจากไหน

คัดลอกจากหน้าสั่งอาหารของร้านบน Wongnai/LINE MAN เมื่อ **20 กันยายน 2026**

**ราคากับเมนูที่ร้านเปลี่ยนได้ตลอด** ตัวเลขในหน้านี้จึงเป็นการประมาณเพื่อให้พอกะยอดได้
ไม่ใช่ราคาที่ผูกพัน ถ้าจะให้ตรงต้องไปดูที่หน้าร้านจริง

รูปอาหาร **ลิงก์** ไปที่ `img.wongnai.com` โดยตรง ไม่ได้เก็บไฟล์ไว้ในโปรเจกต์นี้
(ดู [ADR-0002](./docs/adr/0002-hotlink-menu-photos.md))

## วิธีอัปเดตเมนู

เปิด `src/data/menu.js` แล้วแก้ในอาเรย์ `MENU`:

```js
{ slug: "tom-yum-kung", name: "ต้มยำกุ้ง", price: 120, cat: "kabkhao",
  img: "2026/09/20/xxxxxxxx.jpg", rec: false, desc: "" },
```

| ฟิลด์ | ใส่อะไร |
|---|---|
| `slug` | ชื่ออังกฤษ ตัวพิมพ์เล็ก คั่นด้วยขีด ห้ามซ้ำกับเมนูอื่น |
| `name` | ชื่อเมนูภาษาไทยที่จะแสดง |
| `price` | ราคาเป็นบาท ใส่เป็นตัวเลขเปล่า ไม่ต้องมี ฿ |
| `cat` | `rad-gaeng` · `kabkhao` · `khao` · `namprik` · `drink` · `dessert` |
| `img` | ส่วนท้ายของ URL รูป ต่อจาก `https://img.wongnai.com/p/256x256/` ใส่ `null` ถ้าไม่มีรูป |
| `rec` | `true` ถ้าร้านจัดให้อยู่ในกลุ่ม "เมนูแนะนำ" |
| `desc` | คำอธิบายสั้น ๆ ใส่ `""` ถ้าไม่มี |

จำนวนเมนูในฟุตเตอร์กับตัวเลขข้างชื่อหมวดนับจากอาเรย์ให้เอง ไม่ต้องไปแก้ตามที่อื่น

## ⚠️ ห้ามแก้ slug ของเมนูที่มีอยู่แล้ว

**การเปลี่ยน slug เท่ากับทำรายการที่ผู้ใช้เลือกค้างไว้หาย** เพราะ `localStorage`
ในเครื่องผู้ใช้เก็บเฉพาะ slug กับจำนวน ไม่ได้เก็บชื่อเมนู พอ slug ไม่ตรงกับ `MENU` ใหม่
ระบบจะถือว่าเมนูนั้นไม่มีแล้วและตัดทิ้งเงียบ ๆ

ถ้าร้านเปลี่ยนชื่อเมนูหรือขึ้นราคา แก้ `name` กับ `price` ได้ตามสบาย แต่ `slug` ให้ปล่อยไว้อย่างนั้น
(ดู [ADR-0001](./docs/adr/0001-stable-slug-ids-for-favourites.md))

การ **ลบ** เมนูออกจากลิสต์ทำได้ปลอดภัย — รายการที่ค้างอยู่ในตะกร้าของเมนูนั้นจะถูกตัดทิ้งตอนอ่าน
และเว็บทำงานต่อได้ตามปกติ

## ข้อจำกัดที่ตั้งใจให้เป็นแบบนี้

- รายการที่เลือกอยู่ในเบราว์เซอร์เครื่องนั้นเท่านั้น ไม่ sync ข้ามเครื่องหรือข้ามแท็บ
- ถ้าเบราว์เซอร์ปิด `localStorage` ไว้ เว็บยังใช้ได้ปกติ แค่จำรายการข้ามครั้งไม่ได้ และไม่มีข้อความเตือน
- ไม่มีตัวเลือกย่อยของเมนู (เช่น เผ็ดน้อย ไม่ใส่ผัก) เพราะหน้านี้ไม่ได้ส่งออเดอร์จริง
- ยอดรวมไม่รวมค่าส่งและส่วนลด
- มีธีมสว่างอย่างเดียว ตาม `DESIGN.md` ที่ระบุพื้นขาวล้วน

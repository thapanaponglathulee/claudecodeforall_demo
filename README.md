# วันนี้กินอะไรดี — เว็บแนะนำอาหารไทย

เว็บหน้าเดียวที่สุ่มอาหารไทยให้หนึ่งจาน และจำจานที่ชอบไว้ในเครื่องผู้ใช้

## วิธีเปิด

double-click ที่ `index.html` — ไม่ต้องติดตั้งอะไร ไม่ต้องมี server ไม่ต้อง build

## ไฟล์ในโปรเจกต์

| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | โครงหน้า |
| `style.css` | หน้าตาและธีมสว่าง/มืด |
| `app.js` | ลิสต์อาหาร (`DISHES`) และการทำงานทั้งหมด |
| `CONTEXT.md` | คำศัพท์ที่ใช้ร่วมกันในโปรเจกต์ |
| `task.md` | รายการงานที่ตกลงกันไว้ |
| `docs/adr/` | บันทึกการตัดสินใจที่กลับคำยาก |

## วิธีเพิ่มจานใหม่

เปิด `app.js` แล้วเพิ่ม object เข้าไปในอาเรย์ `DISHES`:

```js
{ slug: 'khao-tom-moo', name: 'ข้าวต้มหมู', nameEn: 'Khao Tom Moo',
  emoji: '🍲', category: 'single', spicy: 0,
  desc: 'ข้าวต้มร้อน ๆ กับหมูสับ มื้อเบาสำหรับเช้าหรือดึก' },
```

| ฟิลด์ | ใส่อะไร |
|---|---|
| `slug` | ชื่ออังกฤษ ตัวพิมพ์เล็ก คั่นด้วยขีด ห้ามซ้ำกับจานอื่น |
| `name` | ชื่อไทยที่จะแสดงบนการ์ด |
| `nameEn` | ชื่ออังกฤษที่แสดงใต้ชื่อไทย |
| `emoji` | emoji หนึ่งตัวแทนรูปอาหาร |
| `category` | `single` (จานเดียว) · `side` (กับข้าว) · `yum` (ยำ-น้ำพริก) · `dessert` (ของหวาน) |
| `spicy` | 0 ถึง 3 เป็นการประมาณ ไม่ใช่ค่าที่วัดจริง |
| `desc` | คำอธิบาย 1-2 ประโยค แสดงเฉพาะบนการ์ดใบใหญ่ |

จำนวนจานในฟุตเตอร์นับจากอาเรย์ให้เอง ไม่ต้องไปแก้ตามที่อื่น

## ⚠️ ห้ามแก้ slug ของจานที่มีอยู่แล้ว

**การเปลี่ยน slug เท่ากับทำรายการโปรดของคนที่เคยกดหัวใจไว้หาย** เพราะ `localStorage`
ในเครื่องผู้ใช้เก็บเฉพาะ slug ไม่ได้เก็บชื่อจาน — พอ slug ไม่ตรงกับลิสต์ใหม่
ระบบจะถือว่าจานนั้นไม่มีอยู่แล้วและตัดทิ้งเงียบ ๆ

ถ้าพิมพ์ชื่อจานผิด แก้ `name` ได้ตามสบาย แต่ `slug` ให้ปล่อยไว้อย่างนั้น
(ดู [ADR-0001](./docs/adr/0001-stable-slug-ids-for-favourites.md))

การ **ลบ** จานออกจากลิสต์ทำได้ปลอดภัย — หัวใจที่ค้างอยู่ของจานนั้นจะถูกตัดทิ้งตอนอ่าน
และเว็บทำงานต่อได้ตามปกติ

## ข้อจำกัดที่ตั้งใจให้เป็นแบบนี้

- รายการโปรดอยู่ในเบราว์เซอร์เครื่องนั้นเท่านั้น ไม่ sync ข้ามเครื่องหรือข้ามแท็บ
- ถ้าเบราว์เซอร์ปิด `localStorage` ไว้ เว็บยังใช้ได้ปกติ แค่หัวใจไม่ถูกจำ และไม่มีข้อความเตือน
- ปุ่มสุ่มดึงจากลิสต์ทั้งหมดเสมอ ไม่สนใจตัวกรองที่เปิดอยู่ในกริด
- ธีมสว่าง/มืดตามค่าของระบบปฏิบัติการ ไม่มีปุ่มสลับ

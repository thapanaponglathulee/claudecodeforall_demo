# ใช้ slug ถาวรเป็นตัวระบุ Dish ไม่ใช่ลำดับในลิสต์

Favourite ถูกเก็บไว้ในเครื่องของผู้ใช้เอง จึงต้องอ้างอิง Dish ด้วยตัวระบุที่ไม่เปลี่ยนตามการแก้ลิสต์
เราเลือก slug อังกฤษถาวรต่อจาน (เช่น `pad-thai`) แทนการเก็บลำดับที่ในอาเรย์ เพราะการเพิ่ม ลบ
หรือสลับลำดับจานจะทำให้ลำดับเดิมชี้ไปยังจานอื่นทันที และไม่มีสัญญาณใดบอกว่าข้อมูลของผู้ใช้เพี้ยนไปแล้ว

## Consequences

- ชื่อ slug กลายเป็นส่วนหนึ่งของสัญญากับข้อมูลที่ค้างอยู่ในเครื่องผู้ใช้ — เปลี่ยนภายหลัง
  เท่ากับทำ Favourite ของคนที่เคยกดไว้หาย
- ต้องตัด slug ที่ไม่มีอยู่ใน Pool ปัจจุบันออกตอนอ่านข้อมูล เพื่อให้การลบจานออกจากลิสต์
  ไม่ทิ้งสถานะค้างไว้

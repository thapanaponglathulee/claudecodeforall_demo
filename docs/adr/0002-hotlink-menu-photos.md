# ลิงก์รูปอาหารไปที่ Wongnai ไม่เก็บไฟล์ไว้ในโปรเจกต์

รูปอาหารทั้ง 46 รูปเป็นของร้านและ Wongnai ไม่ใช่ของเรา การดาวน์โหลดมาเก็บไว้ใน repo
ที่เปิดเป็นสาธารณะเท่ากับเผยแพร่งานที่เราไม่มีสิทธิ์ จึงอ้างถึงรูปด้วย URL ของ
`img.wongnai.com` โดยตรง และเก็บไว้ใน `MENU` แค่ส่วนท้ายของ path

ทางเลือกที่ไม่เอาคือเก็บไฟล์รูปไว้เอง ซึ่งจะทำให้หน้าเว็บไม่พังตามคนอื่นก็จริง
แต่แลกมาด้วยปัญหาลิขสิทธิ์ที่ใหญ่กว่าปัญหารูปแตก

## Consequences

- รูปพังได้ทุกเมื่อโดยเราไม่รู้ตัว ถ้าเจ้าของย้ายไฟล์ เปลี่ยนชื่อ หรือบล็อกการลิงก์ข้ามโดเมน
  โค้ดจึงต้องมีทางลงเสมอ — ดัก `error` ของ `<img>` แล้วสลับไปแสดง emoji ประจำหมวดแทน
  ห้ามปล่อยให้เหลือกรอบรูปแตก
- หน้าเว็บนี้เปิดแบบออฟไลน์ไม่ได้ครบ รูปจะหายทั้งหมด ส่วนอื่นยังใช้ได้ตามปกติ
- เราไม่ได้ควบคุมว่ารูปที่ปลายทางจะเปลี่ยนเป็นอะไร รูปที่แสดงอาจไม่ตรงกับชื่อเมนูในอนาคต
- ถ้าวันหนึ่งต้องเก็บรูปเอง ต้องขออนุญาตเจ้าของร้านก่อน ไม่ใช่แค่ย้ายไฟล์
